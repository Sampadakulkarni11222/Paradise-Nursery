# Paradise Nursery

A React + Redux shopping application for Paradise Nursery, featuring categorized houseplants, a shopping cart, quantity management, and a responsive navigation experience.

## Assignment Features
- Paradise Nursery landing page
- About Us information
- Three plant categories with six unique plants per category
- Add to Cart functionality
- Dynamic cart item count
- Cart quantity increase/decrease
- Remove items from cart
- Cart totals
- Checkout placeholder
- Continue Shopping navigation

## Run
```bash
npm install
npm run dev
```
